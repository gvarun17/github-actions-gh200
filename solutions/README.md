# Solutions

Put each practice-issue solution in `solutions/<topic-slug>/<issue-number>/`, for example `solutions/day-3/14/`.

- Include a short `README.md`: what you did, run links, and what you learned.
- Workflows that must run live in `.github/workflows/practice-*.yml` (GitHub ignores workflow files in subfolders).
- Never commit secrets, tokens or cloud credentials.
